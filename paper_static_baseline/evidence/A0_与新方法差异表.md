# A0与新方法差异表

## 结论

A0保持不变。后续新方法只能修改原QNSGA-II的局部搜索资源分配与学习控制：根据完整排程反馈确定Top-K关键区域，再由Q-learning联合选择`(K,N,b)`。创新实现必须使用独立入口和独立名称，不得回写A0。

| 模块 | A0静态QNSGA-II | 后续新方法 |
| --- | --- | --- |
| 问题范围 | 静态机器–AGV协同调度 | 相同 |
| 染色体 | OS–MS–AS–空载速度–载货速度五段 | 相同 |
| 初始化 | 40%随机/TCM、30%最短时间、30%最低能耗 | 相同 |
| 完整解码 | 原活动MATLAB路径对应的静态完整解码 | 原样复用 |
| 目标 | Makespan与机器忙闲TEC | 相同 |
| 遗传及多目标选择 | 原QNSGA-II规则 | 原样复用 |
| 邻域基本语义 | N1–N6 | N1–N6基本修改语义不变 |
| 搜索区域 | 对状态分组内个体执行原局部搜索 | 增加Top-K关键区域选择 |
| 学习动作 | 只选择N1–N6之一 | 联合选择`(K,N,b)` |
| 搜索预算 | 没有独立的真实解码预算动作 | `b`按真实完整解码次数扣减 |
| 代码入口 | `run_qnsga2` | 必须另设新算法入口 |

比较算法和消融属于后续实验节点，不作为A0冻结完成的前提，也不得伪装成A0自身行为。
