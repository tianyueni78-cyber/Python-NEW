# 静态QNSGA-II基线A0验收清单

## 结论

本清单只判断静态QNSGA-II代码基线A0是否身份明确、正确、可运行、可重复并可作为新方法的公平参照。它不要求A0重新复现来源论文的历史排名，也不判断新方法是否有效。

## A. 身份与边界

- [x] A0明确命名为“基于公开代码实现的静态QNSGA-II基线”。
- [x] 记录Python来源提交、MATLAB来源路径和建立A0的提交。
- [x] 范围仅含静态机器–AGV协同调度。
- [x] 不含订单取消、机器故障、AGV故障或动态重调度入口。
- [x] 不含Top-K、K、b、`(K,N,b)`、新状态、新奖励或其他本文创新。
- [x] 原MATLAB、`python_baseline/`、输入数据和历史结果保持未修改。

## B. A0实际行为规格

- [x] 染色体固定为代码实际五段：OS、MS、AS、空载速度、载货速度。
- [x] 混合初始化固定为代码实际40%随机/TCM、30%最短时间、30%低能耗。
- [x] epsilon固定为代码实际公式及其利用/探索分支。
- [x] Q表的状态、六动作、奖励、初始化、更新和生命周期与A0代码一致。
- [x] N1–N6保持代码实际基本修改语义。
- [x] 完整静态解码保留机器、AGV、空载/载货移动、位置、电量和充电行为。
- [x] Makespan固定为A0代码实际采用的最后加工完成时间。
- [x] TEC固定为机器加工能耗与机器空闲能耗之和；AGV能耗只记录，不进入第二目标。
- [x] 遗传操作和NSGA-II非支配排序、拥挤距离及环境选择保持不变。

## C. 数据、环境与运行

- [x] 记录实例和资源数据的来源、文件清单及SHA-256。
- [x] 记录Python版本、操作系统和实际依赖；不增加非必要依赖。
- [x] 提供一条从仓库根目录执行A0的完整命令。
- [x] 每次运行保存实例、参数、随机种子、配置哈希、源码提交和结果。
- [x] 输出目录不可静默覆盖；失败和中断必须留下记录。
- [x] 真实完整解码次数有唯一计数口径，邻域内部解码也计入。

## D. 正确性与可重复性证据

- [x] 输入读取与冻结数据一致。
- [x] 初始化种群满足40/30/30且所有染色体合法。
- [x] 固定染色体通过工序优先、机器资格、资源不重叠、AGV移动、位置、电量和充电检查。
- [x] 固定染色体的排程、Makespan和TEC形成回归参考。
- [x] Q-learning状态、动作、奖励、epsilon和Q更新通过固定输入测试。
- [x] N1–N6分别通过合法性测试。
- [x] 遗传和多目标选择通过固定输入测试。
- [x] 相同配置和种子可重复获得一致结果；明确允许的元数据差异除外。
- [x] A0小规模端到端运行成功并生成完整manifest。
- [x] 原`python_baseline`测试重跑通过，证明建立A0没有破坏来源实现。

## E. 论文比较准备

- [x] 形成A0与新方法的差异表，唯一允许的行为差异是局部搜索资源分配与学习控制。
- [x] 后续A0和新方法使用同一数据、初始化、解码、目标、种子政策和真实解码预算。
- [x] 正文能够简洁、准确地描述A0；完整参数、命令和来源放入表格、附录或README。
- [x] 对论文与发布代码的差异使用中性来源说明，不将其写成“原论文错误”。
- [x] 明确A0验收通过不等于新方法有效，也不等于原论文历史结论已复现。

## 非A0冻结前置条件

以下事项重要，但不属于本清单的A0冻结门：

- 重新复现原论文“QNSGA-II优于其他算法”的历史结论；
- 论文规模的20次重复实验；
- NSGA-II、MOEA/D和MOPSO的正式比较结果；
- Top-K和`(K,N,b)`新方法实现；
- 新方法相对A0的性能提升；
- 消融、统计显著性和最终论文结论。

这些事项分别在后续算法原型、实验协议和正式实验阶段完成。
