# Results

Only small, reviewed summaries and figures should be committed here.

Raw runs, checkpoints, large arrays, and temporary experiment outputs are
ignored by default. Each committed result must identify the algorithm,
instance, parameter configuration, run count, seed policy, and producing
commit.

`results/runs/`保存未追踪的原始批处理输出：每次运行的配置、种子、代码版本、输入哈希、原始Pareto解、染色体、曲线、运行时和失败信息。仓库只提交小型验收证据。
