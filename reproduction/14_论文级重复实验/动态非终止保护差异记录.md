# 动态非终止保护差异记录

## 现象

动态正式实验在完成64/400组后，`OC_Mk07_t100`第5次重复（种子`3117016433`）持续运行超过22小时。此前同一场景前四次分别只用126—139秒。进程持续占用约一个CPU核心，运行目录只有`config.json`，没有`result.json`。

当前运行器只在整组结束后写结果，没有在初始QNSGA-II、IS、RS和CS之间写检查点，因此保留证据不能进一步区分卡死发生在哪一阶段。

## 根因

共享`variation`先随机选择父代1，再反复抽取与其染色体不同的父代2：

```python
while parents[parent_2_index] == parents[parent_1_index]:
    parent_2_index = ...
```

当候选父代全部相同时，不存在满足条件的父代2，循环无法终止。MATLAB活动`variation.m`同样使用无上限的`while isequal(...)`，因此这是继承的MATLAB非终止边界缺陷，不是电脑休眠、动态事件规模或Q-learning计算量导致。

动态时间预算只能在一代开始前检查；一旦进入该父代选择循环，时间限制无法中断它。

## 用户批准的最小保护

用户批准：保留卡死证据、增加最小保护、只从第65组恢复，不重跑前64组。

保护规则只有一条：

> 如果候选父代中不存在任何与父代1不同的染色体，则本次不执行无法成立的交叉，保留父代并继续原有变异流程。

只要存在不同父代，原随机抽取、交叉、变异及随机数顺序保持不变。目标函数、解码、Q-learning、动态事件、IS/RS/CS和实验预算均未修改。

## 验证

- 修复前：两个完全相同父代、交叉概率1.0的固定测试在2秒后超时；
- 修复后：同一测试正常返回两个原父代；
- 原随机variation合法性与固定种子可重复测试通过；
- Gate 4固定交叉、固定变异及多目标算子参考继续通过；
- Gate 6动态专项10项通过；
- 第14步协议专项9项通过。

## 结果影响

- 前64组均已正常结束，没有触发不可终止状态，继续保留；
- 第65组没有生成正式结果，22小时CPU时间不进入统计或RS/CS预算；
- 恢复后第65组从相同场景、重复和种子重新完整运行；
- 本差异分类为“实现差异：为MATLAB非终止边界增加运行保障”；
- 最终报告必须披露该保护，不得表述为逐项等价于原MATLAB在该边界上的行为。
