# 第14步论文级重复实验实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按已锁定并经用户裁决的论文协议执行静态对比、消融和三类动态重调度重复实验，完整保存原始证据并验收 Gate 7。

**Architecture:** 以第12步不可覆盖记录器为基础，增加可恢复分片、QNSGA-II实测墙钟预算传递、动态场景配置和统计复现审计。原始大体量运行保存在 `results/runs/`，仓库只提交配置、摘要、统计表和差异证据。

**Tech Stack:** Python 3.13标准库、MATLAB只读证据、`unittest`、JSON/CSV、Git/SHA-256。

## Global Constraints

- 种群100，QNSGA-II与消融200代，Mk01–Mk10每组20次。
- 静态对比中每个实例/重复先运行QNSGA-II，其余三算法分别使用该次实测墙钟时间。
- 随机种子在同实例/重复内配对，全部原始结果不可覆盖，失败必须留痕。
- 动态使用三条活跃MATLAB路径各自的资源参数；未恢复的事件目标不得猜测。
- 只有全部运行、原始证据、统计分析和差异审计完成后才能关闭 Gate 7。
