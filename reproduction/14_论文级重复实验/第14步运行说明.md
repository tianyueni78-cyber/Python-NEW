# 第14步正式运行说明

## 已固化规模

- 静态算法对比：4算法 × 10实例 × 20次 = 800次。
- 消融实验：4版本 × 10实例 × 20次 = 800次。
- 动态实验：20场景 × 20次，每次含IS、RS、CS，共1200个策略结果。
- 静态对比的NSGA-II、MOEA/D、MOPSO逐次继承同实例同重复QNSGA-II实测墙钟时间。
- 动态RS和CS逐次使用初始QNSGA-II实测墙钟时间的一半。

## 正式命令

在仓库根目录执行：

```powershell
$env:PYTHONUTF8='1'
python scripts/run_step14_static.py --output results/runs/step14_static_formal
python scripts/run_step14_dynamic.py --output results/runs/step14_dynamic_formal
python scripts/check_gate7.py --static results/runs/step14_static_formal --dynamic results/runs/step14_dynamic_formal
```

两个运行入口均支持断点续跑。再次执行相同命令时，已有成功结果不会覆盖；失败结果会保留并停止，禁止静默跳过。

## 分片方式

如果希望一次只运行一个实例或一次重复：

```powershell
python scripts/run_step14_static.py --output results/runs/step14_static_formal --instance Mk01
python scripts/run_step14_static.py --output results/runs/step14_static_formal --instance Mk01 --repeat 1
python scripts/run_step14_dynamic.py --output results/runs/step14_dynamic_formal --scenario OC_Mk02_t20
python scripts/run_step14_dynamic.py --output results/runs/step14_dynamic_formal --scenario OC_Mk02_t20 --repeat 1
```

不同分片必须指向同一个正式输出目录，程序会累计清单和派生汇总。

## Gate 7通过条件

- 静态成功运行数必须为1600，失败数为0。
- 动态成功场景重复数必须为400，失败数为0。
- 静态和动态汇总文件必须存在。
- Gate 7通过后再生成论文表格对照、结论审计、第14步完成报告并提交最终统计证据。
