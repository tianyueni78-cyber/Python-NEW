# 第09步实施计划

## 验收目标

实现三个相互独立、可运行、可复现的对比算法入口；固定算子与MATLAB参考一致；小规模运行产生合法Pareto解；所有既有Gate和测试不回归；完成中文证据、快照、SHA-256、提交和推送。

## 任务1：MATLAB固定参考

1. 新建`tests/matlab_reference/export_comparators_reference.m`，只调用或逐句复刻无外部入口的MATLAB局部函数，不修改原源码。
2. 固定输出MOEA/D的lambda、邻域、切比雪夫值、邻域替换，以及MOPSO连续位置离散映射、支配与网格信息。
3. 运行MATLAB导出`python_baseline/data/matlab_reference/comparators_step9.json`并人工核对字段。

## 任务2：NSGA-II（TDD）

1. 在`tests/test_step9_comparators.py`先写随机初始化、固定种子重现、小规模合法运行和独立结果类型测试。
2. 运行目标测试，确认因模块缺失而失败。
3. 新建`python_baseline/dfjspt/nsga2.py`，复用已验证的`variation`、锦标赛和环境选择，补充普通随机初始化与停止判断。
4. 新建`scripts/run_nsga2.py`并运行测试至通过。

## 任务3：MOEA/D（TDD）

1. 先写lambda、邻域、倒数权重切比雪夫、邻域更新与MATLAB固定参考一致的测试，再确认失败。
2. 新建`python_baseline/dfjspt/moead.py`，保留0.5跳过评价和MATLAB邻域替换。
3. 新建`scripts/run_moead.py`，验证固定种子小规模合法运行。

## 任务4：MOPSO（TDD）

1. 先写连续位置映射、档案支配、网格、边界和N1—N3局部搜索测试，再确认失败。
2. 新建`python_baseline/dfjspt/mopso.py`，实现最小完整粒子循环和外部档案。
3. 新建`scripts/run_mopso.py`，验证固定种子小规模合法运行。

## 任务5：验收与归档

1. 新建`scripts/check_step9.py`，输出三算法入口独立、固定参考一致、统一目标、预算接口和合法运行证据。
2. 生成`第09步验收证据.json`、`三种对比算法差异记录.md`和`第09步完成报告.md`。
3. 将本步全部新增或修改`.py`按原结构复制到`reproduction/09_实现三种对比算法/Python代码/`，计算并核对SHA-256。
4. 用UTF-8环境重跑Gate 1—5、`python -m unittest discover -s tests -v`、`compileall`和`git diff --check`。
5. 仅在所有检查通过后提交并推送`main`，核对远端哈希与工作树状态。
