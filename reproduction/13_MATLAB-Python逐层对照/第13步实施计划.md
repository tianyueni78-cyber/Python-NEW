# 第13步 MATLAB–Python 逐层对照实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 Gate 1—6 和第12步指标参考组成一套可重复的 MATLAB–Python 逐层对照验收，形成完整证据与差异台账。

**Architecture:** 复用已通过的各 Gate 权威检查和 MATLAB 固定参考，新增一个只读汇总验收器，校验参考文件、快照哈希、差异分类和子检查结果。随机优化器仅验证固定机制、可重复种子和行为边界；统计分布属于第14步。

**Tech Stack:** Python 3.13 标准库、`unittest`、MATLAB `-batch`、Git/SHA-256。

## Global Constraints

- 原 MATLAB 文件只读；验证脚本仅放在 `tests/matlab_reference/`。
- 不修正或重解释已登记的 MATLAB 行为。
- 权威 Python 代码仅在根目录 `python_baseline/`、`scripts/`、`tests/`。
- 第13步新增或修改的 `.py` 同步到本目录 `Python代码/`并校验 SHA-256。
- 不运行第14步论文规模重复实验，不关闭 Gate 7。
