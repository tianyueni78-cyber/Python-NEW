# 第07步差异记录

1. QNSGA-II 链的 `non_domination.m` 在每个 rank 内按拥挤距离降序返回；经典 NSGA-II 链的同名函数只按 rank 分组，再由 `replace_chrom.m` 对截断层排序。分类：实现差异。影响：中间矩阵行序不同，最终环境选择集合一致；Python 显式保留两种核查模式。
2. MATLAB 返回矩阵只保留总拥挤距离。逐目标拥挤分量是临时列，随后被总距离列覆盖并截断。分类：无影响。Python 公共接口只公开总距离。
3. 前沿某目标极差为零时，MATLAB 将该目标的中间个体拥挤分量置为正无穷，而不是零。分类：实现差异。Python 忠实保留。
4. 重复目标行不在非支配排序或 Pareto 过滤阶段去重；最终结果导出时才调用 `unique(..., 'rows')`。分类：无影响。Python 公共过滤保留重复行。
5. NSGA 系四条路径的 `variation.m` 内容相同，MOEA/D 的文件哈希和行为不同，MOPSO 不使用该遗传算子。分类：配置差异。Python 只共享已确认相同的 NSGA 系核心。
6. MATLAB 与 Python 随机数流不同。分类：已记录数值/随机差异。固定选择下交叉和变异逐项一致；随机编排只要求 Python 种子可重复和输出合法。
7. QNSGA-II 按代数停止，对比算法按实测 CPU 时间停止，MOEA/D 还含随机评价削减。分类：配置差异。第7步不建立会改变行为的统一停止器，后续独立算法入口分别实现。

未发现需要用户裁决的潜在 baseline-invalidating 新差异。
