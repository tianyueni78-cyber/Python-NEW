# 第07步共享多目标框架实施计划

## 目标

以固定 MATLAB 输出为真值，用测试驱动方式实现最小公共多目标模块并关闭 Gate 4 的本步算子范围。

## 任务

1. 固定 MATLAB 参考：运行 `tests/matlab_reference/export_multiobjective_reference.m`，保存目标矩阵、rank、拥挤距离、两种排序路径、精英和锦标赛结果。
2. RED：新增 `tests/test_gate4_multiobjective.py`，确认因 `python_baseline.dfjspt.multiobjective` 不存在而失败。
3. GREEN：新增 `python_baseline/dfjspt/multiobjective.py`，只实现设计文档列出的纯函数。
4. 验收入口：新增 `scripts/check_gate4.py`，比较固定参考并输出中文 JSON 证据。
5. 回归：运行 Gate 1、Gate 2 初始化子范围、Gate 3、Gate 4 和全量 `unittest`。
6. 归档：复制本步全部新增或修改的 `.py` 文件到 `Python代码/` 对应目录，生成 SHA-256 清单并逐项核对。
7. 审计：完成中文规格、差异记录、验收证据和完成报告，检查 diff 后提交并推送 `main`。

## 成功标准

- 固定矩阵的非支配 rank 与 MATLAB 完全一致；
- 有限拥挤距离逐项一致，无穷大位置一致；
- QNSGA-II 和 NSGA-II 两种中间顺序均有显式测试；
- 环境选择和固定候选锦标赛结果与 MATLAB 一致；
- 不新增第三方依赖，不创建第8步算法入口；
- 所有既有和新增测试通过，快照 SHA-256 全部一致。
