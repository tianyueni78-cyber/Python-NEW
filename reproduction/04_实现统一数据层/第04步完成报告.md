# 第04步完成报告

## 结论

第4步已完成，Gate 1“输入一致”通过。该结论表示 Python 数据层对 Mk01—Mk10 的工件、机器、工序、候选机器和加工时间与原 MATLAB `benchmarkRead.m` 逐项一致，并且十个实例都能组装成合法的统一 DFJSP-T 输入。

这还不是可运行的完整优化 baseline：染色体、初始化、解码、目标函数及优化循环属于第5步以后。

## 已实现

1. 不依赖第三方包的 Brandimarte `.fjs` 读取器。
2. 工件、工序、机器选择、机器资源、AGV 参数和完整实验输入的数据模型。
3. 与 MATLAB 一致的候选机器升序语义。
4. 依据 `distance_from_xy.m` 从坐标重建曼哈顿距离的 xlsx 转换器。
5. Mk01—Mk10 固定输入及由原 MATLAB 自动生成的参照 JSON。
6. 命令行输入检查入口、Gate 1 审计入口和自动化测试。

## 验证结果

- MATLAB 参照生成：成功（MATLAB 返回码 0）。
- Gate 1 审计：10/10 个实例逐项一致。
- Python 测试：见仓库最新测试输出；测试覆盖十个参照、十个统一输入、资源尺寸和非法截断文件。
- 可运行入口：Mk05 成功读取为 15 个工件、4 台机器、106 道工序、4 辆 AGV。

机器可读的逐实例结果和 FJS SHA-256 位于 `Gate1_输入一致性证据.json`。
